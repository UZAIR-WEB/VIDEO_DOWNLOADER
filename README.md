# VIDEO_DOWNLOADER (v2.0)
Created by **Muhammad Uzair**

A user-friendly web video & MP3 downloader for **YouTube**, **Facebook**, and **Instagram**, ready to deploy on **Vercel**.

## Deploy to Vercel
1. Extract `VIDEO_DOWNLOADER-v3.zip` and upload the contents of `VIDEO_DOWNLOADER` to a GitHub repository.
2. Import the repository in Vercel and click **Deploy**.
